Query Parameters

Use these parameters with GET /customers. All filters can be combined in the same request.

Parameter Type Requirement Accepted values / Description
city String Optional Exact city match, e.g. Jaipur. Case-insensitive.
account_type String Optional Savings, Current or Salary. Case-insensitive.
credit_score_lt Integer Optional Credit score strictly less than this value.
credit_score_gt Integer Optional Credit score strictly greater than this value.
min_balance Number Optional Balance greater than or equal to this amount.
max_balance Number Optional Balance less than or equal to this amount.
min_age Integer Optional Minimum age, inclusive.
max_age Integer Optional Maximum age, inclusive.
active Boolean Optional true or false. Filters account status.
kyc_verified Boolean Optional true or false. Filters KYC status.
sort_by String Optional name, age, balance, credit_score, monthly_income, loan_amount, transactions_count.
order String Optional asc or desc. Default: asc. Used for sorting.
Required parameters: None. If no filters are supplied, all customers are returned. When filters are combined, a customer must satisfy every supplied filter. Invalid numeric, Boolean, sorting or order values return HTTP 400.

Response Format

Successful customer requests return a JSON object. 

{
  "count": 2,
  "filters_applied": {
    "credit_score_lt": "400"
  },
  "customers": [
    {
      "customer_id": 102,
      "name": "Priya Verma",
      "credit_score": 350,
      "city": "Delhi"
    }
  ]
}

The example is abbreviated. The actual endpoint returns all fields for every matching customer.

Statistics endpoint

GET /stats returns customer counts, account status totals, average credit score, total sample balance and the number of customers with a score below 400.

Example Requests

1. Customers with credit score below 400

GET /customers?credit_score_lt=400

2. Active Jaipur customers with credit score below 400

GET /customers?city=Jaipur&credit_score_lt=400&active=true

3. Customers aged 25–40, sorted by income

GET /customers?min_age=25&max_age=40&sort_by=monthly_income&order=desc

4. High-balance savings accounts

GET /customers?account_type=Savings&min_balance=50000

5. All bank statistics

GET /stats
The sample customer dataset is fictional. These examples demonstrate query filtering and do not represent real banking or credit-bureau data.

Errors & Status Codes

Status Meaning Example
200 Request successful Matching customers returned, even if count is zero.
400 Invalid query parameter credit_score_lt=abc or order=sideways.
404 Endpoint not found Requesting an undefined route.

Error responses are returned as JSON where handled by the endpoint. Flask handles undefined routes with HTTP 404.
